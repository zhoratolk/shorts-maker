## Задачи

1. Точки реза по словам (не по сегментам), длительность в `clip.min_seconds`–`max_seconds` после джампкатов.
2. `crop_style` на клип. Deadlock — UI-тяжёлая картинка; `pad` летербоксит уже пустые кадры, поэтому по умолчанию `zoom`. `crop_focus_*` **не проставлять руками** — Phase 11 измерит их сама; ставить явно только там, где измеренное окно проверено глазами и не годится.
3. Джампкаты (`jumpcuts.cut_threshold_seconds: 1.0`), `keep_segments` только если пар больше одной.
4. Сабы из word-таймингов, ремап на спliced-таймлайн, вычитка каждой реплики против звука — Whisper на этом материале путает имена и игровые термины.
5. Бипы: `profanity_spans` по вордлисту, без правки самой шутки.
6. Кандидаты на луп: панч в конце + совпадение картинки на краях. Луп-клипы уходят отдельным PLAN.json и проходом `--loop-enabled` без `--outro-enabled` (иначе `outro_card` конкатом убивает шов).
7. Метаданные на три площадки + `moment_tag` каждому клипу (иначе клип выпадает из learning loop ретеншна).

## Гейты

- Ни один клип не уходит в рендер без `moment_tag` и постера.
- Тизер cold-open проверяется по кадрам: на 08-02 и на августовском резерве все кандидаты падали на UI (карта/сонар/тёмная станция) — если повторится, cold_open выключается на весь батч.
- Сверить длительность после джампкатов фактом, а не расчётом.
